# 일용직 판정 도구

엑셀(원천2_일용직 / 고객개요 시트)을 끌어다 놓으면 사람별 근무기간으로 일용직 여부를 판정하고,
일용직의 근무일별 소득세·지방소득세, 월별 합계(원천4 집계용), 근무일별 표를 보여주는 HTML 한 파일짜리 도구입니다.

- 파일은 브라우저 안에서만 처리되며 서버로 전송되지 않습니다.
- 3개월 이상(입사일 또는 첫 근무일 ~ 마지막 근무일) → 일용직 아님(상용 검토)
- 소득세 = (일당 − 150,000) × 6% × 45%, 원 미만 버림, 1,000원 미만 0 / 지방소득세 = 소득세 × 10%
